## What I'm Building

### 🕶️ SHADOW

A local-first AI assistant designed to work across environments while maintaining persistent conversation memory and local capabilities.

**Current direction:**

`LLM → Agent → Tools → Memory → Retrieval → Long-term Context`

Built with Python, Ollama, SQLite, and a modular provider/tool architecture.

---

### 🧬 Project Epsilion

The long-term vision behind SHADOW's memory and storage infrastructure.

A private, self-hosted memory and storage layer designed to eventually give AI systems their own persistent knowledge space.

**Goal:** make AI memory something I actually control.

---

### ⚡ Drev CI

A lightweight, self-hosted CI runner focused on simplicity and developer control.

- Docker-based execution
- YAML pipelines
- GitHub webhook triggers
- Real-time build logs
- Server/runner architecture
- Next.js dashboard
- Go + SQLite backend infrastructure

---

### 🌌 Obliquity

A software brand and experimental ecosystem focused on building polished, modern developer products.

Built around a space-inspired identity with a focus on **engineering + design**.
